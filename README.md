# Tv-os

A minimal Python prototype of a TV operating system.

## Features
- Boot sequence
- App launching and closing
- Channel switching with validation
- Runtime status inspection

## Run
```bash
python /home/runner/work/Tv-os/Tv-os/tv_os.py
```

## Test
```bash
python -m unittest discover -s /home/runner/work/Tv-os/Tv-os -p "test_*.py"
```
